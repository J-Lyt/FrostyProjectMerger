# Frosty Project Merger
A plugin for [Frosty Toolsuite (Dragon Age: The Veilguard)](https://github.com/J-Lyt/FrostyToolsuite) which merges multiple project files into one. 

To use, click on the ``Import Project`` button on the toolbar and select the project you would like imported.

**WARNING:** Be careful when allowing the plugin to overwrite files that have already been modified in a project. If you allow it to, it will overwrite them regardless of the damage it could cause.
